# 游尺 · 游戏 UX 品质监控 — 本地试用版

## 启动

1. 安装 Node.js 24 LTS（https://nodejs.org/）。最低支持 Node.js 22.13。
2. 将下载包完整解压。Windows 双击“启动平台.cmd”；macOS 在终端进入本目录运行 `node server/local.mjs`，也可运行“启动平台.command”。
3. 浏览器打开 http://localhost:3210 。启动窗口需要保持开启，关闭窗口会停止服务。

不需要 npm install。界面、Excel 导入组件及数据库操作均已包含，运行时无需访问 chatgpt.site 或加载外部资源。设计方案和 PM 链接仍需要其原有网络及访问权限。

## 开始试用

- 在“项目设置”修改项目名称。
- 在“需求与验收”下载 Excel 模板，用真实需求替换示例行，再导入；更新前可查看差异。
- 新建或编辑需求，添加设计方案链接，并选择当前参考方案。
- 完成评分和否决项，提交后由负责人确认。终版通过后存档，修改前先重新打开。
- 优化问题独立保留，按“待优化 → 优化中 → 待复验 → 已通过”跟进；复验失败回到优化中。

## 验收规则

基础功能60%、细节与全局体验30%、视觉与落地质量10%。总分低于80、任一维度低于60或任一否决项不通过即不达标。采用未取整分数判定。普通子项按适用项平均，“不适用”不计入，每个维度至少有一个适用项。

## 数据与权限

这是本机单人试用版，默认本地用户为UX负责人，不使用ChatGPT登录；它不模拟实际团队身份认证。服务只监听127.0.0.1，不能用于对外或团队共享部署。多用户使用需要另外配置身份认证和访问控制。

数据保存在本目录 `data/ux-quality.sqlite`，停止服务后备份整个 `data/` 文件夹即可。数据不会与已发布Sites版本自动同步，也不会上传到GitHub。重新启动后记录仍保留。不要删除data文件夹。

PM自动同步尚未接入，当前支持表格导入和手动编辑。

## 故障处理

- 提示找不到node：安装Node.js 24 LTS后重新打开终端/启动文件。
- 端口冲突：设置 `UX_LOCAL_PORT`（例如3211），再运行，按启动窗口地址访问。
- 提示node:sqlite不可用：升级Node.js至24 LTS。
- Excel导入失败：使用模板表头，填写必填字段，评级为S/A/B，每次不超过500条。

如在云环境运行，localhost指云环境本身，不能直接在你的电脑访问。要提供团队入口，需要经授权配置HTTPS转发、访问控制或部署到公司内网。
